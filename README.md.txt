# Unusual Whales API Proxy Server

Backend proxy server for OnOurWays trading platform.

## Quick Deploy to Railway

1. Go to [Railway.app](https://railway.app)
2. Click "New Project"
3. Select "Deploy from GitHub repo"
4. Choose this repository
5. Railway will auto-detect Node.js and deploy
6. Add environment variable: `UW_API_KEY` = `23ef1cc4-407b-421f-99bc-202323a78799`
7. Copy your Railway URL
8. Update your website's index.html with the Railway URL
